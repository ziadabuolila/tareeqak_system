# طريقك — لوحة التحكم والـ API

واجهة Next.js وواجهات API متصلة بقاعدة PostgreSQL، ويمكن استخدام Supabase. لا يحتاج النظام إلى Laravel منفصل.

## التشغيل المحلي

يتطلب Node.js 22.13 أو أحدث وقاعدة PostgreSQL متاحة. انسخ إعداد الاتصال من `web/.env.example` إلى `web/.env.local` وضع بيانات الاتصال الخاصة بقاعدة البيانات.

قبل التشغيل الأول، طبّق مخطط `web/supabase/schema.sql` على قاعدة البيانات بعد إعداد دور التطبيق `tareeqak_app`. تحديثات المخطط لا تُطبّق تلقائيًا عند أول طلب API؛ أعد تطبيق الملف عند إضافة تغييرات قاعدة بيانات.

```powershell
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) للوحة التحكم. استخدم أدوات PostgreSQL أو لوحة Supabase لإدارة البيانات.

## حسابات الدخول والبيانات

- دخول اللوحة مخصص للموظفين والمديرين المسجلين في تبويب **المستخدمون ← الموظفون**.
- تطبيق Android يستخدم واجهات المواطنين؛ التسجيل ينشئ الحساب في تبويب **المستخدمون ← المواطنون**، والدخول للموبايل يتم برقم الهاتف.
- بيانات الدخول والجداول تعتمد على قاعدة PostgreSQL التي تم إعدادها.
- تنتهي جلسة اللوحة بعد ساعة من عدم النشاط، وتُفحص الصلاحية من الخادم قبل فتح الصفحات المحمية.

لإضافة مدير يدويًا، مرّر بياناته من متغيرات البيئة ثم شغّل `npm run admin:create` من مجلد المشروع. يجب أن تكون قاعدة PostgreSQL جاهزة أولًا.

## واجهات Android API

- `POST /api/citizen/register`
- `POST /api/citizen/login`
- `GET /api/citizen/me` مع Bearer token
- `GET/PATCH /api/citizen/profile` لعرض وتحديث بيانات المواطن
- طلبات موافقة الجهاز الجديد موثقة في `api/README.md` وتتطلب مخطط قاعدة البيانات المحدّث
- `GET /api/citizen/reports` و`POST /api/citizen/reports`
- تسجيل دخول لوحة الموظفين: `POST /api/admin/login`
